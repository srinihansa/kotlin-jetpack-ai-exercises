# Kotlin Jetpack AI Exercises

This repository contains hands-on Android and AI learning projects built with Kotlin, Jetpack Compose, and modern DevOps practices.

## Projects

### Smart Notes
A Jetpack Compose note-taking application used to learn Android fundamentals.

### AI Document Assistant
An Android application that integrates with a local AI backend for document analysis.

### Backend API
Shared FastAPI service providing AI endpoints.

### Infrastructure
Docker, CI/CD, configuration, and infrastructure assets.

### Scripts
Automation scripts for development and CI.

### Docs
Architecture, design notes, and project documentation.

## Planned Technology Stack

- Kotlin
- Jetpack Compose
- Android Studio

- Python
